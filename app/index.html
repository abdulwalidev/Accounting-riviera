⚠ Delete Entity

Remove an accidentally created entry — admin only. This is a soft delete: the entry (with its rooms and payments) disappears from every screen immediately. Nothing is destroyed — an admin can still restore it directly in the Supabase SQL Editor — but there is no Undo button inside the app, so search carefully and confirm you have the right guest.
