Search Tips

Live results — Results refresh as you type. Use any combination of Name, Mobile, CNIC/Passport, Email, or Res ID — more fields means tighter matches.
Match scoring — Each row is scored 100–1000. Exact matches on Mobile, CNIC/Passport, or Res ID weigh more than partial name matches; multi-field matches score higher.
Re-using a guest — Click Select on any result to start a new check-in pre-filled with that guest's profile (name, contact, ID, marketing, BTC, payment preferences).
Brand-new guest — If the guest has never stayed before, click Create entirely new check-in above to skip search and go straight to a blank form.
